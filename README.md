# 📊 Curso de Estadística Descriptiva Multivariada

Este repositorio reúne los materiales del curso de **Estadística Descriptiva Multivariada**, abarcando desde los fundamentos teóricos hasta la implementación práctica en software estadístico.

A lo largo del contenido se exploran técnicas como:

- Medidas descriptivas multivariadas
- Análisis de Componentes Principales (PCA)
- Análisis de Correspondencias
- Métodos de Clasificación

El repositorio está diseñado como un recurso de aprendizaje tanto para estudiantes que cursan la asignatura como para cualquier persona interesada en el análisis de datos multivariados y técnicas modernas de ciencia de datos.

## 🎯 Objetivos de aprendizaje

Al finalizar el curso, el estudiante será capaz de:

- Comprender los fundamentos matemáticos de los métodos multivariados.
- Aplicar técnicas de reducción de dimensionalidad con datos reales.
- Interpretar resultados mediante visualizaciones estadísticas.
- Implementar métodos multivariados en R de forma reproducible.

## 🛠️ Requisitos

Se recomienda tener conocimientos básicos de:

- Programación en R
